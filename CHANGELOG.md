# v0.2.1

**Bugfix Release**

* Removed the OnesaUCE Starting Collection setting from Companion.
* Companion now automatically forces OnesaUCE `firstCollection` to `Main`.    This setting actually represents the top level collection, not the starting collection.

# v.0.2.0

**Feature Release**

* New Collections screen for browsing collections and their related media.
* New Logs screen for viewing the Companion log file and the log files from OnesaUCE
* New Settings screen for adjusting various settings in OnesaUCE, including the ability to enable or disable Autostart

* Added check if a newer version of Companion is available
